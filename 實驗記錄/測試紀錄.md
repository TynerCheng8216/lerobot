#### 怎麼刪除專案 git

在專案資料夾路徑執行以下指令

- ubuntu: `rm -rf .git`

- windows: `Remove-Item -Recurse -Force .git`

---

#### 抓 git 專案 clone remote

- `git clone <repo url>`

---

#### 新增分支 new branch

1. VSCode 點擊左下角 main
2. +Create new branch...
3. 自定義分支名稱
4. 再次點擊左下角 main 就能切換

---

#### 合併回原本主分支 branch merge

1. 先切回要接收的分支(譬如 main)
2. 點擊左側 Source control -> Changes ... -> Branch -> Merge...
3. 選擇中上方列表的分支

---

#### 刪除分支 branch delete

同 merge 只是 Merge... 換成 Delete Branch...

### NVIDIA 顯卡 相關使用

#### 使用步驟說明

1. 從 Python 專案確認 PyTorch 版本(因為 PyTorch 決定了 CUDA 、 Python 版本)
2. NVIDIA 官網能找出 CUDA 可以對應哪個最低的驅動版本
3. 透過 ubuntu 指令查詢目前可用的驅動版本
4. 安裝到至少符合 CUDA 需要的驅動版本

---

#### 1. 從專案查看 PyTorch 版本

- 方法一、 查看 `pyproject.toml` 搜尋 pytorch 後面有 +cu128 就代表 cuda 版本使用 12.8
- 方法二、 進入專案虛擬環境 `python -c "import torch; print(torch.version.cuda)"`
- 方法三(uv)、 `uv run python -c "import torch; print(torch.__version__, torch.version.cuda)"`

---

#### 2. 查詢 CUDA 版本對應最低的 Driver

[CUDA 對應列表查詢](https://docs.nvidia.com/cuda/cuda-toolkit-release-notes/index.html#)

[CUDA 對應列表查詢2](https://docs.nvidia.com/deploy/cuda-compatibility/minor-version-compatibility.html)

---

#### 3. 查詢可用 NVIDIA GPU Driver

```bash
# 更新 apt 套件以及 安裝 ubuntu-drivers 工具，已安裝就不用重複執行
sudo apt update
sudo apt upgrade -y
sudo apt install ubuntu-drivers-common -y

ubuntu-drivers devices
```

---

#### 安裝驅動 GPU driver

指定版本:

```bash
sudo ubuntu-drivers install nvidia:<版本>
```

備註: 不指定版本會由系統安裝建議版本

---

#### (選用) 安裝 Container Toolkit

如果開發使用 Docker ，容器需要使用到 GPU 需要安裝

1. 安裝指令

    ```bash
    # 如果是第一次安裝，先執行以下指令加入 NVIDIA 官方 Repository
    sudo apt install -y curl gnupg2 ca-certificates

    curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey \
    | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg

    curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list \
    | sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' \
    | sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list

    # 如果之前已經加入 NVIDIA 的 APT Repository，只需要：
    sudo apt update
    sudo apt install -y nvidia-container-toolkit
    ```

2. 讓 Docker 知道如何使用 NVIDIA GPU，並讓設定正式生效:

    ```bash
    sudo nvidia-ctk runtime configure --runtime=docker
    sudo systemctl restart docker
    ```

3. 測試 Docker 是否能使用 GPU

    ```bash
    sudo docker run --rm --gpus all ubuntu nvidia-smi
    ```

## 【survey】

### 研究目標

以 SmolVLA 為基礎，研究 Vision-Language-Action 模型的資料效率、視覺特徵處理或輕量化架構，並在機器人模擬環境中驗證改良效果。

---

### SmolVLA 是一種 VLA 模型

[SmolVLA: A vision-language-action model for affordable and efficient robotics](https://arxiv.org/html/2506.01844)

[SmolVLM: Redefining small and efficient multimodal models](https://arxiv.org/html/2504.05299)

- 是一種 VLA 模型
- 比起 NVIDIA:3B 、 OpenVLA:7B, 它算是小參數只有 450M
- 有辦法單卡微調
- 模型結構概念是 VLM + Action Expert
- VLM 使用 SmolVLM2(內有SigLIP)
- Action Expert 使用 Flow Matching(一種Transformer)

### LIBERO 是一種 Benchmark 的測試基準

### LeRobot 是整合 SmolVLA 、 LIBERO 、 Mujoco 的框架

### PEFT 是微調的一種方式，局部非全域微調

Parameter-Efficient Fine-Tuning，是專門用來調整大型預訓練模型的技術方法(LoRA、Adapter Tuning...)

### 安裝專案

1. 抓 lerobot (github)

    ```bash
    git clone https://github.com/huggingface/lerobot.git
    cd lerobot
    ```

2. 主機安裝 FFmpeg

    ```bash
    sudo apt update
    sudo apt install -y ffmpeg

    # 確認可以用
    ffmpeg -version
    ```

3. 使用 uv 建立專案 .venv 虛擬環境


5. 確認 LeRobot CLI 可以用

    ```bash
    uv run --no-sync lerobot-eval --help
    ```
